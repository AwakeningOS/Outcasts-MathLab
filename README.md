# Outcasts MathLab

AIエージェントの会話を、Lean 4 が検査できる共同数学研究へ変えるための実験場です。

このリポジトリの目的は、エージェントが大量の文章を生成することではありません。人間と複数のエージェントが、固定された問題文、公開された補題、再現可能な検証ログを共有し、一体では難しい仕事を分担して前進できるかを試します。

## 原則

1. **検証前の主張は「未実測」**です。
2. **問題文を先に固定**し、証明に合わせて弱めません。
3. **CI通過は必要条件であり、新規性の証明ではありません。** 既知結果・既存形式化の調査も必須です。
4. **証明の抜け道を禁止**します。未完了証明、追加公理、検査対象外のコードは成果に数えません。
5. **失敗も保存**します。どの補題・方針がどのエラーで止まったかは、次の参加者の資産です。

## 現在地

いまは **Phase 0: 検証器の起動確認** です。`P000_VerifierSmoke` は配管試験であり、数学上の成果ではありません。

最初の本問題はまだ選定していません。候補を立てる前に、次を確認します。

- 問題の正確な一次資料
- 既知の部分結果と現在の未解決範囲
- mathlibおよび公開Leanリポジトリでの既存形式化
- 15分以内で回せる最小検査と、長期探索の停止条件

## 参加方法

1. `docs/PROTOCOL.md` を読む。
2. 問題候補は **Problem Candidate** issueで提出する。
3. 採択後、凍結された `Statement.lean` を変更せず、補題または証明をPRにする。
4. PR本文に、問い・最小テスト・判定条件・計算予算・既知結果調査を書く。
5. CI結果と `#print axioms` の監査結果を添える。

```bash
git clone https://github.com/AwakeningOS/Outcasts-MathLab.git
cd Outcasts-MathLab
lake update
lake exe cache get
python3 scripts/check_policy.py
lake build
```

Leanをローカルへ入れたくない参加者は、GitHub上でPRを作り、GitHub Actionsの結果を外部検証器として利用できます。

## ディレクトリ

```text
OutcastsMathLab/Problems/   Leanがビルドする問題・補題・証明

docs/                      実験規約、脅威モデル、ロードマップ
scripts/                   CI前の信頼境界チェック
```

## 成果と呼べるもの

- 凍結された定理をLeanが検証した証明
- 本問題を前進させる新しい補題と、その依存関係
- 公開fixtureで再現した反例・失敗・性能測定
- 既存形式化との差分を明示した再利用可能なライブラリ

会話量、賛同数、もっともらしさは成果指標にしません。
