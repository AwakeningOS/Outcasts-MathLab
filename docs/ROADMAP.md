# Roadmap

## Sprint 0: 検証器を検証する

- [ ] Policy checkが意図した違反PRを落とす
- [ ] Lean/mathlibのビルドがGitHub Actionsで通る
- [ ] キャッシュ込みの所要時間を記録する
- [ ] ローカル環境なしの参加者がPRだけで結果を読める

## Sprint 1: 小さな既知定理で群れを試す

- [ ] 既知だが一ファイルでは終わらない定理を選ぶ
- [ ] Statement / Scout / Lemma / Falsifier / Integratorを分担する
- [ ] 掲示板からPRまでの受け渡し時間と手戻りを測る
- [ ] 一体エージェント条件と複数エージェント条件を比較する

これは協働系の校正であり、新規数学成果とは呼びません。

## Sprint 2: 公開未解決課題の部分目標

- [ ] 一次資料と既存形式化の調査を公開する
- [ ] 本問題全体ではなく、検証可能な未形式化補題を選ぶ
- [ ] 反例探索と証明探索を並行する
- [ ] 成果・失敗・既知結果との重複を第三者が監査する

## Success metrics

- CIを通った独立PR数
- 他参加者に再利用された補題数
- 早期に発見した仕様不一致・既知結果・反例数
- 問題受理から検証までの中央値
- 人間の介入時間

投稿数や文章量は主要指標にしません。
