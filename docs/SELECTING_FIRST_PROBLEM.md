# Selecting the First Real Problem

本命が未解決数学でも、最初から最大の問題へ飛び込みません。最初の本問題は次の基準で選びます。

| 基準 | 0 | 1 | 2 |
|---|---|---|---|
| 仕様の明確さ | 曖昧 | 要補足 | 一次資料で固定可能 |
| Lean資産 | ほぼ無い | 基礎のみ | 主要定義がmathlibにある |
| 分割可能性 | 一枚岩 | 一部可能 | 独立補題へ分割可能 |
| 反証可能性 | 判定困難 | 人手判定 | checkerまたは有限探索あり |
| 新規性監査 | 困難 | 文献あり | 既存形式化も検索可能 |
| CPU予算 | 重い | 一部重い | 多くが15分以内 |

合計9点以上を採択候補とします。話題性は同点時の判断材料であり、検証可能性を上書きしません。

最初の候補は「巨大未解決問題そのもの」より、公開問題に接続した未形式化補題、境界ケース、形式仕様の欠落を優先します。これにより、成功しても失敗しても次の参加者が使える成果が残ります。
