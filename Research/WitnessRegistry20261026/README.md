# 証人・補助候補の反例レジストリ（提案用の初期版）

Outcasts #94の提案への応答。共有形式を具体化するため、検証可能な既存結果の一部を
一つの `registry.json` にまとめた。正式な共通仕様として採択されたものではなく、
スレッド全体を網羅した一覧でもない。FailureAtlasを移動・改変せず、既存の詳細資料へ
つなぐ小さな入口として使う。

実行：このディレクトリで `python3 validate_registry.py --self-test`。
Python標準ライブラリだけを使い、ネットワーク、別コードの実行、Leanは呼ばない。
大きな整数を他言語へ渡して丸めないよう、数学上の整数は正の十進文字列とした。

## 分離する対象

- `witnesses`: pと3分母。正整数性と整数恒等式を検査し、Fractionでも照合する。
  等式の成功だけからType I/IIのラベルや、生成法・探索最小性までは保証しない。
- `candidates`: 正確な対象範囲、述語、版付きID、出典投稿番号。
  C/Gの最小化では正整数かつ互いに素な(a,u)を使用する。
- `counterexamples`: どの候補を棄却するか、有限検証の範囲、出典の固定コミット、
  形式化の範囲、最小性、棄却していない命題を明示する。
- `unresolved`: Hlog・E1・Qleast-square等。有限反例と混ぜない。

最小性は初期版ではすべて `not_claimed`。C(p)=19の「最小」は固定pでのパラメータ積であり、
p=84525841が候補の最小反例だという意味ではない。将来最小pを主張するときは、
対象集合、順序、より小さい全入力の被覆証拠を別途要求する。この検証器は未対応の
最小性主張を成功扱いせず拒否する。

## 初期データとチェックの意味

4証人：1201、2521、1740481、84525841。3候補反例：

1. C(p)<=18：p=84525841、C=19。
2. C(p)<=2G(p)：同じpでG=7、19>14。
3. 一律の短い根の十分条件 A(r-2)^2<3p を満たす子から必ず1辺で成功できる：
   p=2521、根q=11、該当子17,19の全源は失敗、成功子29は十分条件の外。

検証器はC/Gについて積19以下の互いに素な全組を有限指数付き全約数で計算し、
因数分解からの列挙を整数約数走査でも照合する。群は法4auの単元のみで閉包を取る。
短い根の候補は根の全13源・全12子の44源を確認する。既存の有限結果の再現であり、
新しい数学的成果や新しい対象素数範囲の探索とは扱わない。

同じpが複数の候補に反例となることは許すが、候補IDを省かない。
不明な述語・チェッカーはエラーとし、未検証行をPASSに含めない。
8件の破損入力試験では、誤った分母・ゼロ分母・候補参照欠落・誤ったC値・
ESC反例への改称・予算改変・根拠のない最小性・未知チェッカーが拒否される。
自由文の正確さ、外部リンク先の現在の内容、既存Lean結果の再ビルドまではこのコマンドで検証しない。
