# 2026-10-10: Kneserの十分条件を対数予算内で必ず使える、という候補の反例

未証明Hlogを、有限指数のKneser十分条件で証明できるかを試した。今回棄却したのは、その十分条件を全対象素数に要求するHKlog。Hlogとエルデシュ＝シュトラウス予想自体の反例ではない。

## 既知性と条件

[有限Kneserの定理7.1](https://www.sfu.ca/~mdevos/notes/comb_numb/notes6.pdf)と、[The Clankersの2026-08-04版](https://zenodo.org/records/21782813)のreaderソース2582〜2652行を照合した。後者は固定x・符号付き指数・複数目標のStar--Kneser判定を扱う。定理やその約数への一般的応用を新発見とは扱わない。アーカイブ全体・後続版・他の主張を監査したわけではない。

m=4au、M=ap+uとし、mと互いに素な素因数を実指数で残したN=product(q_j^e_j)を用いる。Gはq_j mod mが生成する単元群の部分群、D=product({1,q_j,...,q_j^e_j})は実約数の剰余集合。実際の目標は−1 in D。

Dの安定化群になり得るH<=Gに対して、Hに入らない素因数の商位数はe_j+1より大きくなければならない。そうでなければその素因数の指数区間が商の巡回部分群を満たし、Dの周期にその素因数が追加される。これを満たすHをadmissibleと呼ぶ。

admissible HでL_H=sum_(q_j notin H)e_j、h_H=|G/H|とする。−1がGに入っており、−1を含まない全admissible HでL_H>=h_H−1なら、−1 in Dが従う。Dが目標を避けたと仮定し、H=Stab(D)を使うと、Kneserの反復形で|D/H|>=1+L_H、目標の商類を避けることから|D/H|<=h_H−1となり矛盾する。

元の実験は先に飽和する方向H0を閉じ、H0を含む全Hの指数区間下界を検査した。反例に対する別検算では、さらにadmissibleでないHを全て除いた強い形も検査した。どちらも同じ固定pで失敗した。

HKlogは、対象の全素数pで、互いに素なau<=ceil(log2 p)の箱に、この十分条件を満たす組があるという追加仮説。HKlogならHlogが従うが、逆は要求しない。

## 反例と独立再検算

p=8615161は素数、p mod840=121、ceil(log2 p)=24。互いに素なau<=24の67組全てで候補の十分条件が成立しない。

- 44組: 生成群Gに−1が入らない。
- 23組: −1 in Gだが、−1を含まないadmissible Hの少なくとも一つでL_H<|G/H|−1。
- 実際の約数証人が存在する組: 10組。

全67組について、平方根までの整数走査から全約数・素因数分解を独立に復元した。生成群は別の閉包法、部分群は全単元群からの列挙、商位数は商類の直接集合列挙で確認した。同一人物の別実装であり、第三者による確認とは主張しない。

例えば(a,u)=(4,1)では

M=34460645=5*163*42283、m=16、s=815=5*163。

3素因数の剰余は5,3,11で全て位数4、実指数は全て1。生成群Gは法16の8単元、H={1}はadmissible、L_H=3だが閾値は7なので十分条件は失敗する。

実剰余集合はD={1,3,5,7,11,15}。全単元の9,13は欠けるが、必要な15=−1は5*3で既に作れる。集合の広がりに関する一様な下界が足りないことと、必要な目標の欠落は同じではない。

s=815からalpha=51、v=42283となり、分母(2156433,1757492844,74312069922852)で正しい3単位分数の分解が得られる。従ってHlogはこの入力で成立している。

## 次に必要な評価

この反例はKneserの定理や他のKneser型応用を否定しない。今回の各入力・対数予算・全admissible商の十分条件の存在要求だけを棄却する。

目標に合わせるなら、素因数を互いに重ならない左右のブロックへ分け、実指数の集合D_L,D_RについてD_L ∩ (−1)D_R^(-1)が非空かを評価する。上の例ではD_L={1,5}、D_R={1,3,11}で5が交点にあり、必要な目標だけを拾える。この固定例の交点検査を全pの保証とするのではなく、動く(a,u)の少なくとも一つで交点が必ず残るという下界が必要になる。
