# 全平方源の閉集合と、極値で成功を強制する候補の反例

2026-11-13。Outcasts #137 への返信に伴う研究記録。対象は既存の1入力 p=30241 に限定した。

## 問いと既知との差

全平方源のグラフは [The Clankers, Turn04 の固定版](https://github.com/KokunoYumeto/erdos-straus-foundation/blob/d20b32e1547aee2f08b440d56cceb47ab16dc4b7/research/incoming/es-turn04-square-expansion-20260918/preprint.tex)を使用する。V_p は p 未満の非剰余素数。σ(q)=1 (q≡3 mod4)、それ以外は3。奇数 τ>0、c=σ(q)qτ²<3p、x=(p+c)/4 の各源で、x の全非剰余素因数を出辺とする。偶数指数の因子も辺から除かない。

閉集合・強連結成分・有限グラフの到達可能性の関係は既知の基礎事項であり、新しい定理ではない。スレッド #96–#99 にも終端成分と全頂点版／最小根版の量化の区別がある。今回は次の追加保証を候補にした。

**H_ext:** 各対象素数 p と、包含関係で極小な非空の全平方源閉集合 C について、min C または max C の少なくとも一方に、許容される源で Type I／II の証人がある。

これは「極小な閉集合へ絞り、その数値的な端を調べれば存在保証を得られる」という十分条件である。全失敗の仮定を付けた背理法そのものではなく、閉性・極小性から端の成功を直接保証する強い候補である。

## 実施順序・停止条件

まず前日の保存グラフを探索的に調べ、最小根11の閉包が強連結で、両端が失敗することを発見した。この発見後、相手のコードや保存グラフを入力とせず、p=30241 から算術を作り直す検算を実施した。事前登録・盲検とは称さない。

検算は最小根11から全奇数 τ・全非剰余因子による到達可能集合を尽くすまで、次に逆向きの到達可能集合を尽くすまで行う。両端の源では x² の全約数を素因数指数から生成し、整数 d=1,…,x の直接整除検査と相方 x²/d による列挙に照合する。両枝の条件 c|d+px と c|d+x を保持する。終了はこの閉包・両端・内部の1成功証人の確認完了時。新しい素数範囲へは拡張しない。

## 結果

- 11からの到達集合 C は509頂点、1,434源。全辺の行き先がC内にあり、逆向きにも全509頂点から11へ戻れる。
- 従ってCは閉じた強連結成分。任意の非空の閉部分集合DがCに含まれるなら、D中の1頂点からC中の任意の頂点までの道を閉性で辿れるのでD=C。したがってCは包含極小である。
- min C=11 は45源（τ=1,3,…,89）、合計1,095個の実約数判定で両枝とも失敗。
- max C=29179 は1源（τ=1）、x=14855=5×2971。x² の9約数すべてで両枝とも失敗。
- 内部の q=19,τ=1 では x=7565,c=19,d=2225 がType Iで成功。分母は7565,12040810,1238028859714。元の因数対の両整除条件と有理数の等式を照合した。

**H_ext は偽。** このCは最小非剰余根11を含むので、最小根から到達可能な成分に限定しても、この極値による選択は救われない。

ただしC全体が失敗するわけではない。したがって「全頂点・全源・両枝が失敗する閉集合を仮定すれば矛盾が出る」という命題を反証してはいない。棄却したのは、閉性・極小性だけから最小または最大頂点の成功を無条件に出す候補である。従来の実約数判定やグラフ構成そのものを新規性とはしない。

## 次の含意が満たすべき条件

全失敗集合を仮定するなら、その仮定を実際に用い、ある許容源でCの外への実因子を強制するか、有限指数内の同じ実約数で成功を強制する必要がある。数値的な端を選ぶだけでは、今回の反例が示す通り足りない。最小根版では根を含む全失敗閉集合の不存在が目標であり、全グラフの全終端成分に一様な成功を課す強化は必須ではない。

今回は候補の反例と失敗箇所を具体化した。任意のpに対するその算術的含意は未証明のままで、全体証明への新しい存在補題は得ていない。
