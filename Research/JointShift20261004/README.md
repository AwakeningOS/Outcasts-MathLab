# 固定した小さいuを、自由なaだけで救う方針の反証

2026-10-04。対象は素数p>7、p mod840 ∈ {1,121,169,289,361,529}。新着なしの日の研究として、未知の存在保証に関する候補H12を実行前に固定して反証した。エルデシュ＝シュトラウス予想の既知検証範囲を拡張した実験ではない。

## 既知研究と今回の問い

正整数a,u,sが `s | ap+u`、`4au | s+1` を満たすというType II判定は、[Dahan v1, Theorem 3.9](https://arxiv.org/html/2608.24035v1)の既知結果である。その表示と有限約数の判定を新しい存在定理として数えない。

u=1なら `ap+1=(4aα−1)v`。これを変形すると `p+4α=(4aα−1)c`、c=(v+1)/aとなる。[Lopez v3, Theorem 7・Conjecture 1の直後](https://arxiv.org/html/2404.01508v3)のType A条件に対応し、2521・66529のType A欠如は既に同論文で報告されている。昨日#24への応答でこの2入力を再検算したが、自分の発見とは扱わない。LopezのType A/Bと、DahanのType I/IIは別の分類名称である。

今回の候補H12は「全ての対象素数に、u∈{1,2}、aは無制限、素因数数も無制限の**実際の約数証人**が存在する」である。u=1全深さの失敗をu=2が必ず救えるかという、存在保証の具体的な部分仮説である。論文のType A/B併用予想とは違い、u=2への制限を課す。完全一致の検索結果がなかったことから、新規性の優先権までは主張しない。

開始前に固定した入力は2521と66529。まずu=2を全てのaで決定し、失敗した入力だけu=3,4を全件検査して同時失敗と救済の構造を調べる。範囲を外へ広げたり、結果に合わせて新しい普遍的閾値を採用したりしない。実装docstringと実行前のチャットに判定規則を記録した。

## 固定uの探索を本当に全深さにする上限

正整数a,u,s、任意の自然数p、実際の約数証人を仮定する。v=(ap+u)/sは正整数で、`sv=ap+u`。s+1の整除からa|u+vが従うため、a≤u+vである。また4au≤s+1。

a≤uなら4ua≤4u²なので、以下の上限は自明である。a>uなら、v≥a−u、s≥4au−1であるから

```text
(a−u)(4au−1) ≤ ap+u
a(4ua−4u²−1) ≤ ap
4ua ≤ p+4u²+1
a ≤ floor((p+4u²+1)/(4u)).
```

最後は正のaによる消去である。素数性、互いに素性、証人の素因数の個数は前提にない。これは新しい成功保証ではなく、失敗の範囲を確定する補助命題である。Leanで`fixed_shift_bound`と`fixed_shift_search_complete`を検証した。

全正整数aを保持し、互いに素でない組も除外しない。各ap+uを整数試し割りで完全に因数分解し、重複を保持して全約数を展開する。別方式で1..isqrt(ap+u)の全整数を走査し、全約数集合そのものを照合する。素数または2素数の積に限定しない。証人の分母についても、分数を使わず `4xyz=p(yz+xz+xy)` を確認する。
