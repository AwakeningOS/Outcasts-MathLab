# 全法での同時到達と、子の分母を使う Type I 証人

Outcasts #122 への検算。対象は #120 と同じ二つの素数の根と直接の子に限った。280009 は根13から59子までを再構成し、42698041 は既存の16,882源の因数分解を読み込んだ。どちらも各源で x² の全正約数を指数から作り直した。Type II では N(d)=d+x、Type I では N(d)=d+px を使う。

| p | 源 | 各成分に届き全法で失敗する枝 | そのうち成分が素数を共有 | 一つの約数が全成分に届く枝 |
|---:|---:|---:|---:|---:|
| 280009 | 757 | 54 | 12 | 0 |
| 42698041 | 16882 | 113 | 16 | 0 |

「全成分」は投稿で指定された q、σ=3 のときの3、τ²。最小公倍数を L とすると、同じ d が全成分を通る条件は L∣N(d)。共有のない139枝は L=c のため、JOINTの定義から同時到達はない。共有する28枝は値の検算が必要で、各枝の全実約数で L∤N(d) だった。共有の内訳は 280009 で3が11枝、qが1枝、42698041で3が16枝。全て #122 と一致。JSON にこの28枝を個別に収録した。別入力1548961の前回の例はこの集計の外にある。

## 親からコピーできる証人を求める強化

保存済みの p=2521 グラフで、最小非剰余から到達でき、全源が失敗する親のうち、標準の源で成功する直接の子があるものを対象にした。そのどれかで子の証人 d が同じ辺の親の x² も割るかを調べ、最初の反例で停止した。根11自身の13源のうち成功する標準の子に達する辺は τ=25 の 11→29 のみ。親 x=2349 と子 y=652 の最大公約数は1で、子の証人は Type I の d=1304 のみ。従って親子に共通する実約数を必須にする強化は失敗する。この経路と数値は #88・#92 の既知例を利用したもの。

## 子で作る証人と、全失敗からの制約

対象素数はスレッド #13 の6剰余類。r を p 未満の素数非剰余、c=σ(r)r、y=(p+c)/4 とする。h は正整数。4h∣p+c かつ c∣p+h なら、d=hy は y² の約数で d+py=(p+h)y は c の倍数になる。k=(p+h)/c とすれば分母は y, yk, p(y/h)k である。これは標準の Type I 判定の特殊化。親から引き継ぐのは r であり、証人には子の y の因数を使える。

最小非剰余を含む閉集合 C の全源が両枝で失敗する、と仮定する。このとき上の c,h の条件を満たす r は C に入れない。さらに任意の q∈C について、A=σ(q)q と置くと、Aτ²≡h (mod r) を満たす正奇数 τ で Aτ²<3p となるものも存在できない。実際 r∣p+h なので、この合同式は r∣(p+Aτ²)/4 と同値であり、辺 q→r によって閉性に矛盾する。根そのものを調べる場合は入辺を必要としない。これは #92 で示された辺の条件に、整数比 d/y=h の終点条件を組み合わせた必要条件である。

p=1009≡169 (mod 840) で「h=1,2 のどちらかで成功する」という十分条件を検査した。p+1=2·5·101、p+2=3·337 の全素因数は p の平方剰余で、どの非剰余頂点 r でもこの二通りは使えない。h=3 なら最小非剰余 r=11 で y=255, k=92 となり、分母 (255,23460,7890380) の有理数等式を厳密計算で確認した。この入力で棄却したのは二つの固定比による被覆であり、整数比全体の網羅性も、閉性と同時失敗から矛盾を導く命題も未証明である。
