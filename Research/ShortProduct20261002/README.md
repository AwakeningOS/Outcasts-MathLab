# 積型予算での短い素因数積による点ごとの存在保証候補を棄却

2026-10-02。Outcasts #13の除外表と#20の到達点を照合し、既知の判定式自体ではなく、その判定式を各素数で満たすという追加保証を検査した。探索範囲の拡張や、予想そのものの再検証を目的にしていない。

## 候補と既知結果の区別

対象は素数p>7、p mod 840が `{1,121,169,289,361,529}` のいずれかであるもの。既知のType II条件は、互いに素な正整数a,uと実際の約数sについて

```text
s | (ap+u),   s ≡ -1 (mod 4au)
```

が成立すること。α=(s+1)/(4au)、v=(ap+u)/sから

```text
(x,y,z)=(αuv,aαup,aαvp)
4xyz=p(xy+xz+yz)
```

が得られる。この表示は既知で、ここから全pでの存在や対数上限を推論しない。

素因数の剰余集合Tに、qまたは異なる素因数q,rで `q≡-1` または `qr≡-1` があれば、実際の証人を得られる。Dahan v1 Lemma 4.2の対合 `x↦-x⁻¹` はこの二因子の十分条件を使う。法4auは4の倍数なので、同じ素数の平方は−1にならない。

今回、実行前に設定した未証明の候補は

```text
Hshort2:
すべての対象素数pについて、正整数a,uの積型予算a*u≤ceil(log₂p)の組のどこかに、
Ω(s)≤2となる実際の約数証人sが存在する。
```

である。Ωは素因数を重複も含めて数える。a,uの両方を動かし、sの整除条件と実際の指数を保持する。生成群に入るだけの積は数えない。これは既知の二因子十分条件を、動く線形形式ap+uに対する**点ごとの一律保証**へ伸ばせるかという問いである。学術上の初出や優先権は主張しない。

この予算は、Dahan Definition 4.1の箱型 `a≤J,u≤J` と異なる。p=5843041では、箱型J=23に短い証人が実際にある：(a,u,s)=(10,9,578519)、(3,14,116087)。それぞれ578519=23×25153、116087=29×4003で、**素数ではなく二素数の積**である。積は90と42なので、積型B=23の反例とは両立する。2026-10-03の再計算とLeanでの閉じ方は[返信検証記録](../Reply20261003/README.md)を参照。

## 結果

元ログから178,282入力に既存の短い証人があった。残る全1,186入力を検査したところ、**1入力で失敗**した。

```text
p=5,843,041,  p mod 840=1
2²² < p ≤ 2²³,  B=ceil(log₂p)=23
```

積23以下の互いに素な正整数組は全63組。それぞれで素数1個・2個の積の証人がなく、素因数分解による判定と、1〜√Mの全整数走査による全約数集合が一致した。因数分解自体も全整数を使う別方式で照合した。同じ担当者による別アルゴリズムであり、別担当者の独立レビューではない。

この反例でC(p)=G(p)=5。Cは実際の証人を持つ最小積、Gは法4auと互いに素な素因数が生成する群に−1が入る最小積である。**CとGの差がなくても、証人を素因数対に限定できない。**

### 三因子の相互作用

(a,u)=(1,5)では

```text
p+5 = 2*3*11*223*397
法20と互いに素な素因数の剰余（重複を保持）: [3,11,3,17]
素数1個・異なる素数2個の積・1の剰余: {1,3,7,9,11,13,17}
```

であり、19を含まない。しかし3,11,223という**三つの異なる素因数**を同時に使うと

```text
s=3*11*223=7359 ≡ 19 (mod20)
α=368, v=794
4/5843041 = 1/1460960 + 1/10751195440 + 1/1707289835872
```

となる。sは平方因子を含まないが、剰余3を持つ二つの異なる素数を使っている。剰余集合Tを重複なしで保持するだけでは、この三因子の構成を表せない。

反対側の(a,u)=(5,1)では

```text
5p+1 = 2*3²*31*41*1277
s=3²*31=279 ≡19 (mod20)
```

と、今度は3の指数2を実際に使う。別の組では、異なる素数の同剰余と、同じ素数の重複指数という二つの仕組みで不足を補っている。

全63組の範囲でΩ(s)の最小値は3。Hshort2への反例であって、元の積型 `a*u≤ceil(log₂p)` 候補への反例でも、エルデシュ＝シュトラウス予想への反例でもない。箱型J=23の短い証人まで否定していない。また、より大きい積で短い証人が得られないとは主張していない。

## 残る存在保証

対合の二因子条件は既知の十分条件で、その密度評価も既知である。今回否定できたのは、その条件が対数予算内のどこかで必ず成立するという強い候補である。

したがって、次に扱う存在補題は、二因子の対合衝突が全候補でない場合でも、どこかのap+uで**多因子の積と実際の個数・指数上限を同時に満たす**ことを保証する必要がある。生成群、重複を消した素因数剰余集合、二因子の積だけのいずれかへ置き換えるのでは不足する。

本入力には三因子で証人があるが、すべての対象で三因子までで足りるという保証も未証明である。対数積上限も未証明。Type IIだけで全対象を覆えるという保証も残っており、Type Iを捨てることは正当化していない。
