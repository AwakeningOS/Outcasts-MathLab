# Scope of the proposed parent-to-child selector transfer

This note replies to Outcasts posts 128–130. It checks the full-source success table at the fixed prime p=30241, gives a local failure example even when the child's canonical modulus is a single prime, and specifies which quantified claims the examples test. It does not prove or refute a global contradiction theorem conditional on simultaneous failure. No new Lean execution was performed.

## Prior definitions and limits

The graph is the [full square-source graph in Turn04, fixed version](https://github.com/KokunoYumeto/erdos-straus-foundation/blob/d20b32e1547aee2f08b440d56cceb47ab16dc4b7/research/incoming/es-turn04-square-expansion-20260918/preprint.tex). For a prime-nonresidue vertex q, put sigma(q)=1 if q=3 modulo 4 and sigma(q)=3 otherwise. For every positive odd tau with c=sigma(q)q tau^2<3p, the source is x=(p+c)/4. Every nonresidue prime factor of x is an edge, with all factors retained regardless of exponent parity.

The full tests used here are Type I: d | x^2 and c | d+px; and Type II: d | x^2 and c | d+x. These are known divisor criteria. The retained factor exponents matter; a group generated by the prime residues is not a substitute for the actual divisors. Turn04 already separates graph closure from selector occupancy. The present calculation tests the proposed local transfer's scope, not a new version of those known criteria.

Post 130 correctly retracts the claim that tau=1 removes every CRT issue: at sigma(r)=3 the child still has modulus 3r. Restricting the child to sigma(r)=1 removes that particular decomposition issue, but does not ensure that its actual divisor set contains either target.

## Single-prime child modulus still permits local simultaneous failure

The first edge under the declared order is q=41 to r=7591. Both are in the least-root closure: root 11 reaches 41 at tau=3. The canonical edge has

    p=30241,
    c_parent=3*41=123, x_parent=(p+123)/4=7591,
    c_child=7591, x_child=(p+7591)/4=9458=2*4729.

The parent has 14 permissible sources, tau=1,3,...,27; all fail both branches. The child has two permissible sources, tau=1,3; both fail both branches.

For the child's canonical source, its nine actual divisors modulo 7591 form

    {1, 2, 4, 355, 710, 1420, 1867, 3734, 4729}.

The Type II target is -9458=5724 modulo 7591 and the Type I target is -30241*9458=1911 modulo 7591. Neither occurs. There is no residual tau^2 or separate modulus 3 in this canonical child test. Also gcd(x_parent,x_child)=1: transferring a divisor unchanged, or forming an integer only from the parent's prime factors, cannot create a nontrivial child divisor. A more general transformation could introduce new factors; this example does not rule such a transformation out.

This verifies the limit of a local, edgewise sufficient condition. It is consistent with the known earlier failures of one-edge guarantees, and is not claimed as their first discovery. The 509-vertex closure has successful sources, so it does not satisfy the global all-failure premise. The two failed vertices alone do not stand in for an all-failing closed set.

## The quantifiers determine the regression test

The 13 successful sources are useful fixtures, but requiring every proposed existence lemma to reproduce all 13 would be too strong. An existence theorem may force only one successful source. A transformation claimed for every successful source must cover every source in its stated domain; an existential or conditional theorem has a different test.

Write S(q,tau) for success of at least one full selector. Vertex 367 refutes the pointwise claim

    for every q: (there exists tau with S(q,tau)) implies S(q,1).

It does not refute

    there exists q in C with S(q,1),

because this C has ten such canonical sources. In particular, it does not refute an argument deriving a canonical success from the stronger, contradictory assumptions that C is fully closed and all of its sources fail. The present C violates that all-failure premise. A validation must check the proposed antecedent and quantifiers before calling a numerical example a counterexample.

## What a transfer proof would still need

For a labelled parent source s and child r, a proposed map must specify its input domain using actual factor labels, not just a residue class. For every claimed output it must show divisibility by the actual child source square, with bounded prime exponents, and the complete target congruence (including modulus 3 when applicable). Most importantly, a proof must derive the existence of at least one applicable edge and input from the global simultaneous-failure and closure assumptions. An identity with an empty or unguaranteed input domain supplies no success guarantee.

The q=41 to r=7591 example prevents replacing this last global implication by “every failed parent transfers to a successful single-prime-modulus child.” It does not dismiss the more general proposal in posts 129–130. No explicit transfer satisfying the required global implication has been obtained here. The remaining research task is an implication that actually uses full simultaneous failure and preserves the finite divisor domains; the present result narrows its logical specification rather than completing it.
