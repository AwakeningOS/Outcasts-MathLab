# ψ 型の障害は u を平方剰余に強制する

`OutcastsMathLab/Research/PsiObstruction.lean`

相互法則からすぐに出る帰結で、エルデシュ＝シュトラウス方程式についての新しい定理ではない。
有限の「失敗の地図」で事前に登録して数値で確かめた予測（H2'）を、Lean で証明したもの。

## 背景

Dahan の対 `(a, u)` と素数 `p` について、`ψ(q) = J(−au | q)` と置く。
`ap + u` の奇素因数がすべて `ker ψ` に入るとき（ψ 型の障害）、ψ(−1) = −1 なので
`ap + u` に `s ≡ −1 (mod 4au)` の約数はない。840 の平方類の素数で調べた失敗のうち、
`u ≤ 6` では 86%（QR 型のうち）がこの型だった。

## 定理

| 名前 | 内容 |
|---|---|
| `jacobi_eq_one_of_prime_factors` | `n ≠ 0` の奇素因数 `q` がすべて `J(p\|q) = 1` なら、`n` の奇数の約数 `m` すべてで `J(p\|m) = 1` |
| `psi_obstruction_forces_residue` | `p ≡ 1 (mod 8)`、`u > 0`、`ap+u` の奇素因数がすべて `J(p\|q) = 1` なら `J(u\|p) = 1` |
| `psi_eq_jacobi` | 素数 `q ∣ ap+u`、`gcd(a,u) = 1` なら `J(−au\|q) = J(p\|q)` |
| `psi_kernel_forces_residue` | 上の 2 つを合わせた ψ の形: ψ 型の障害なら `J(u\|p) = 1` |
| `nonresidue_shift_escapes_psi` | 対偶: `J(u\|p) = −1` なら、`ap+u` に `ψ(q) ≠ 1` の奇素因数 `q` がある |

`p` は素数である必要がない（`p ≡ 1 (mod 8)` だけを使う）。

## 主張しないこと

- `J(u|p) = −1` のとき証人が**ある**とは言わない。ψ 以外の二次指標（`d ∣ 2au` の Kronecker 指標）、
  部分群型・指数型の失敗は残る。実際、H2' の計算では `J(u|p) = −1` の行の 89.7% が失敗し、
  その内訳は指数型 16,976 / QR 型（ψ 以外）13,070 / 部分群型 2,915 だった。

## 数値の照合（Lean の外、事前登録済み）

840 の平方類の素数 `p < 10⁶`（2,370 個）、`u ∈ {11,13,17,19,23}`、`a ≤ 6` の 71,100 行:
`J(u|p) = −1` の 36,750 行で ψ 型の失敗 0 件。`J(u|p) = +1` の 34,350 行では 22,370 件
（検査に判別力があることの確認）。素因数分解と整数の約数走査の二方式で成否が全行一致。
