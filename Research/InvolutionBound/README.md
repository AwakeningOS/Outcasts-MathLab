# Dahan の対合による上限（Lemma 4.2 の形式化）

`OutcastsMathLab/Research/InvolutionBound.lean`

**これは文献の補題の形式化であり、新しい結果ではない。**（2026-10-10 に「既知の補題」から書き直した。Dahan arXiv:2608.24035v1 は査読前のプレプリント。
補題はここで Lean で独立に証明したので、補題そのものの正しさは Dahan の査読に依存しない。）
Dahan（arXiv:2608.24035）Lemma 4.2: `m ≥ 1`、`M` の `4m` と互いに素な素因数の剰余の集合を `T ⊆ (ℤ/4m)^×` とする。
`M` に `≡ −1 (mod 4m)` の約数がなければ `|T| ≤ φ(4m)/2`。

証明の要点は対合 `ι(x) = −x⁻¹`。`−1` は `4m` を法として平方でない（4 で割った剰余を見る）ので `ι` に固定点はなく、
`(ℤ/4m)^×` を大きさ 2 の軌道 `φ(4m)/2` 個に分ける。`x` と `ι(x)` が両方 `T` にあれば、対応する相異なる素数
`q₁ ≡ x`、`q₂ ≡ ι(x)` の積が `M` を割り、`q₁q₂ ≡ −1` となって仮定に反する。よって `T` は各軌道と高々 1 点で交わる。

Dahan が指摘するとおり、素因数の生成する部分群で議論する方法は `(ℤ/4m)^×` の指数が 2 を超えると破綻する
（16 を法として 3 と 7 の約数剰余は −1 を避けるが、⟨3, 7⟩ は −1 を含む）。対合の議論は法を問わず無条件に成り立つ。

## 定理

| 名前 | 内容 |
|---|---|
| `neg_one_ne_sq` | `ZMod (4m)` で `x² ≠ −1`（`ZMod 4` に写すと平方は 0, 1 のみ） |
| `card_le_half_of_fixedPointFree_involution` | 数え上げの核: 単射 `ι` と、`ι` の像と交わらない有限集合 `T` について `2|T| ≤ |α|` |
| `iota` / `iota_injective` / `iota_ne_self` | `ι(x) = −x⁻¹` は単射で固定点がない |
| `card_le_half_totient_of_no_neg_one_divisor` | 各元が `M` の素因数の剰余である任意の `T ⊆ (ZMod (4m))ˣ` について、`M` に `4m ∣ d+1` の約数がなければ `2|T| ≤ φ(4m)` |
| `primeResidues M n` | Dahan の `T`: `M` の `n` と互いに素な素因数の剰余を `(ZMod n)ˣ` の有限集合として定義 |
| `dahan_involution_bound` | Lemma 4.2 そのもの: `2 · |primeResidues M (4m)| ≤ φ(4m)` |
| `no_witness_bound` | 証人条件への特殊化: pair `(a, u)` に `p` の証人（`s ∣ ap+u`、`4au ∣ s+1`）がなければ、`ap+u` の素因数の剰余は `(ℤ/4au)^×` の高々半分 |

`M = 0` や `m = 0` は仮定から除外される（`M = 0` なら `d = 4m−1` が仮定に反し、`m` は `0 < m` を仮定）。

## 主張しないこと

- 等号の達成（`T = ker χ`、`χ(−1) = −1` の二次指標）は形式化していない。
- これは証人が**無い**ことの必要条件で、存在については何も言わない。
- 有限の失敗の地図（840 の平方類、`p < 10⁶`、53 pair）では、失敗 107,627 行すべてがこの条件を満たしていた（Lean の外の観察）。
  指数型の失敗の 92% は `|T|` が上限の 0.2 倍以下で、上限が効くのは `ker χ` に収まる QR 型。
