## 1. The fixed-source radical lemma

Let c>1 be odd, gcd(c,x)=1, R=rad(c), and let K_m be the subgroup of U(m) generated by the prime factors of x. The reduction U(c)→U(R) is surjective with kernel of odd order h=c/R. If k∈K_c reduces to -1, then b=-k belongs to the kernel, so b^h=1 and k^h=-1. Thus -1∈K_R implies -1∈K_c; the reverse follows by reduction. Because x∈K_m, this is also the equivalence for the Type II target -x. Standard prime-power unit-group structure and CRT supply the kernel computation; see Conrad, Sections1–2:

https://kconrad.math.uconn.edu/blurbs/gradnumthy/primepowerunitsandGLnQ.pdf

This keeps x fixed. It does **not** say that changing tau while keeping rad(tau) fixed leaves the answer unchanged, since x=(p+3r*tau²)/4 changes. A concrete source example is p42698041,r41:

## 2. A sufficient bounded-exponent lifting lemma

Write x=∏g_i^{e_i}. For an actual radical witness d|x² with d≡-x mod R, set

    z_i = v_{g_i}(d)-e_i,       -e_i <= z_i <= e_i,
    a = d*x^{-1} mod c,        b = -a mod c,
    s = ord_c(b).

Since b≡1 mod R, its order s divides h=c/R and is odd. Consequently a^s=-1 mod c. If the additional budget inequalities

    |s*z_i| <= e_i for every i

hold, define

    d' = ∏g_i^{e_i+s*z_i}.

All exponents lie in [0,2e_i], so d' is a positive divisor of x². Dividing by x in U(c) gives d'/x=a^s=-1, hence d'≡-x mod c. This proves sufficiency.

The extra budget condition is not furnished by the odd-kernel argument. Failure of this particular lift alone does not rule out a different full witness. No quantitative success bound or uniform existence assertion is obtained from this lemma.

## 4. Two scope corrections for reuse

In post105's pinned contract and an outer code comment, the size parameter is written as(d+x)/c. The implemented check correctly uses the reduced sum(d+x)/gcd(d,x). The actual parameter is

    k=(d+x)/(c*gcd(d,x))=(u+t)/c.

For p1201,x306,c23,d108, gcd(d,x)=18. The unreduced quantity is18, exceeding307/23; the reduced k is1, satisfying the bound. This corrects the wording, not the code's reduced-sum assertion or its reported zero-success tables.

Also, a radical actual-divisor witness that fails at c is not itself a counterexample to **group** reduction for Type I. At the tau27 row above, both Type I groups contain the target (K_c is all58320 units); there is a radical Type I divisor20334858227 and no full-c Type I divisor. ## 5. Research consequence and execution scope

A hypothetical all-failed successor-closed set containing the least nonresidue must defeat actual bounded-exponent witnesses, not merely group membership. Radical reduction cannot by itself eliminate this set: the lifting exponent may exhaust the available prime multiplicities. Any uniform existence argument using this route must also force sufficient exponent room at some reachable source, or construct a different bounded representative. Neither conclusion is proved here. E₁ stays refuted; Qleast-square and the global conjecture remain unproved by this work.
