## 3. 列挙範囲が完全である理由

正整数 `p,x,y,z` に対し `c=4x-p>0`、`M=px` と置くと、分数等式は `cyz=M(y+z)` と同値です。
この等式から `(cy-M)z=My>0`、`(cz-M)y=Mz>0` が得られ、両因子 `a=cy-M`、`b=cz-M` は正です。

次の恒等式により `ab=M²` です。

```text
(cy-M)(cz-M)-M² = c(cyz-M(y+z))
```

`y<=z` なら `a<=b` なので `1<=a<=M`。逆に、この範囲の因数対で `a+M` と `b+M` がcで割り切れれば、復元した正整数y,zは元の等式を満たします。
したがって、固定したxについてy,zの任意の打切り上限はありません。xの入力範囲は301〜306に限定されています。

この段落の全単射・正値性を含むPython列挙器全体の正しさは、まだLeanで形式化していません。後述のLeanファイルが証明するのは、因数対の代数的恒等式と等式の同値性です。

## 4. 一般補題の仮定と結論

### 因数対の同値性

仮定: `c,M,y,z` は整数、`c≠0`。

結論:

```text
cyz=M(y+z)  iff  (cy-M)(cz-M)=M²
```

上の恒等式と整数の零積性から従います。素数条件や互いに素という条件は不要です。正整数解を列挙する用途では、節3の正値条件を加えます。

### 1201の例を含む既知の合同類

仮定: 整数 `t>=1`、`n+23=408t`、すなわち `n=408t-23`。

構成:

```text
x=102t,  y=6tn,  z=17tn
```

このときn,x,y,zは正であり、`4xyz=n(xy+xz+yz)` が成立するので、`4/n=1/x+1/y+1/z` が得られます。
分数での証明は `1/y+1/z=23/(102tn)` と `n+23=408t` を使うだけです。
`t=3` が `n=1201, (x,y,z)=(306,21618,61251)` に対応します。

これは `n≡385 (mod 408)` の正整数を扱う既知の構成の具体化です。素数だけに限定されません。
Elsholtz–Tao, Proposition 1.9 のType II族 `n≡-e (mod 4ab)` に `a=6,b=17,e=23` を入れたものに当たり、`e | a+b` と `gcd(e,4ab)=1` を満たします。新規の解法とは主張しません。
